Player

Playback stays close to the release check.

The Player is the listening side of Finalizer. Main Player, External Player Window, Mini Player, and Embedded Player keep listening available while the release check runs.

MasterDeliveryCheck

See the selected target — and the other outcomes.

When offline analysis is ready, MasterDeliveryCheck shows the selected target result first. It can also show how the same track would translate to other target families such as CD, vinyl, or TV.

Target

Selected target

See whether the planned release passes the profile you actually selected for the project.

Translate

Other delivery families

Compare the result against other target options to understand where the same master may or may not fit.

Result

Clear outcome

Get a pass/fail style result with practical suggestions when the file does not reach the selected target.

Master Chain

Preview changes before you decide what to do next.

If a track fails the target, use the Master Chain to load or simulate processing changes and compare Source against Processed.

BasicEQ

Start from a neutral state.

Use the chain as a preview area before deciding what the file needs. The goal is not to guess — it is to hear and check the result.

Adjustment preview

See what a move could change.

Preview how an EQ move, a few dB, or a mastering AU plugin could affect the signal before revising the master or sending notes forward.

Saving chain setups is planned later.

Meters

Meters show why a target passes or fails.

Finalizer uses target LEDs, EBU R128 style loudness views, peak, true peak, stereo, low-end mono behavior, and clip state to make the technical state visible. The final decision still belongs to the listener.

Finalizer Report

End with a result you can read, save, or send.

Finalizer can create a report as text or PDF. It shows whether the release passed, lists warnings per track, and keeps the delivery result documented.
