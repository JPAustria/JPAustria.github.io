Release notes

Finalizer 1.0

The first public release of Finalizer brings offline playback, analysis, metering and release documentation into one focused macOS workflow.

Version 1.0

Finalizer 1.0 is the initial release, designed to help check, listen to and document audio releases before delivery.

Highlights

Project-based audio import, local playback, delivery-focused analysis, loudness metering, signal chain tools and exportable release reports.

Built for repeatable checks without cloud upload, tracking or account setup.

Playback

Includes a clean offline player for local listening, playlist playback and quick review without requiring a project workflow.

Hardware requirements

Finalizer 1.0 is built for Apple silicon Macs. A minimum of 8 GB memory is recommended for basic use, with 16 GB preferred for larger projects, longer release checks and smoother multitasking.

Version 1.0 has been tested on an Apple silicon Mac with M2 Pro.

Analysis and delivery control

Includes offline analysis, loudness and delivery checks, low-end inspection, BPM/key-related workflow support and project status feedback.

CD standards can be checked through one focused filter that drops formats that do not fit Red Book style delivery requirements.

Metadata and tags

Inspect audio tags and patch artist or album metadata where needed, helping release files stay cleaner before export, handoff or archive.

Meters and visual tools

Includes live metering views for loudness, level, stereo balance and delivery confidence during playback and review.

Reports

Finalizer can generate release documentation to support handoff, review and technical delivery decisions.

Notes

Loudness, delivery and technical checks are guidance tools. Final acceptance remains subject to the requirements and decisions of platforms, distributors, broadcasters, labels, clients or other receiving parties.
