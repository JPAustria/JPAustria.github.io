Finalizer quick guide

A compact guide for getting around Finalizer: player, projects, analysis, meters, reports and release checks.

1. What Finalizer is

Finalizer is a local macOS audio tool for playback, release checking, metering and documentation. It is designed to help review audio files before export, handoff or delivery.

Audio files stay on your Mac. Finalizer does not require an account or cloud upload for its normal workflow.

2. Basic workflow

Import audio, analyze the files, review the results, listen in the player, check meters, then export or document the release where needed.

A typical flow is: import → analyze → review → listen → report → deliver.

3. Player

The Player is for local listening and playlist playback. It is useful for quick checks, auditioning files and listening without setting up a full project.

4. Projects

Projects keep release files, analysis results and delivery status together. Use projects when you want a repeatable release check instead of a quick listen.

5. Analysis

Analysis checks technical properties such as loudness, low-end behavior and delivery-related status. Results are meant to guide review, not replace the final listening decision.

Imported audio files are not changed by analysis. Finalizer reads the original file and keeps results separately, so the source file stays untouched.

For analysis and processed review, audio is handled internally in a 32-bit floating-point processing path to keep the checks precise while working locally.

6. CD standards filter

The CD standards filter helps identify files that do not fit Red Book style delivery expectations. It is a focused way to catch wrong formats before they move further into the release workflow.

7. Metadata and tags

Finalizer can inspect audio tags and patch artist or album metadata where needed. This helps keep release files cleaner before export, handoff or archive.

8. Meters

Meter views help check loudness, level, stereo behavior and playback status. Use them while listening to understand what the file is doing in real time.

9. Master Meter

Master Meter gives a focused view of level and loudness while reviewing audio. It helps compare the original source with the processed signal before you make final decisions.

Source and Processed work like a live A/B comparison for your ears: Source is the incoming file before the Master Chain, while Processed is the signal after the active processing path. Use both to hear what changed instead of guessing by volume alone.

10. Master Chain

The Master Chain provides a focused processing area for review and mastering support. Use it carefully and always compare Source and Processed while listening.

11. Reports

Reports collect useful release information and technical checks into a document that can support handoff, archive or delivery review.

12. Hidden trophies

Some release checks include playful hidden rewards. Battle the flames, free Clipper and keep moving through the release check.

13. Troubleshooting

If something looks wrong, first check the file format, file location, project selection and whether the file can be played normally by macOS. For support, include the Finalizer version, macOS version, Mac model and a short description of the issue.
