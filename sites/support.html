Support

Help for Finalizer.

Finalizer is built for local macOS audio analysis, playback and delivery-control workflows. This page collects the practical support information needed before contacting support.

1. Before contacting support

Please make sure you are using the latest available version of Finalizer and the latest compatible macOS update for your Mac.

If the issue is related to a specific audio file, try the same workflow with another file first. This helps separate app issues from file-specific format, permission or metadata problems.

2. Useful information to include

A good support request should include the Finalizer version, macOS version, Mac model, a short description of what happened, what you expected, and the exact workflow that triggered the issue.

Screenshots are useful for interface problems. For audio-related issues, please describe the file type, sample rate, channel layout and whether the issue happens during import, analysis, playback, signal-chain preview or report export.

3. Audio files and privacy

Finalizer is designed as a local tool. Please do not send audio files unless they are specifically requested for troubleshooting and you have the rights to share them.

If a file is confidential, describe the problem instead of attaching the file. In many cases, a screenshot, report result or short technical description is enough.

4. App Store purchases

If Finalizer is distributed through the Apple App Store, purchases, refunds, family sharing and App Store account issues are handled by Apple. Finalizer support can help with app behavior, but cannot directly manage Apple ID billing or refund decisions.

5. Known limits

Finalizer helps check and prepare releases, but it does not guarantee acceptance by a streaming platform, distributor, broadcaster, label or client. Delivery requirements can change and final acceptance is decided by the receiving party.

Third-party Audio Unit plug-ins may behave differently depending on the plug-in version, installation, copy protection, macOS version and host compatibility.

6. In-app bug report

Finalizer includes an in-app bug report option. When used, it prepares a support email with useful technical details such as app version, macOS version, Mac model and relevant hardware information.

The report is prepared for review before sending. Please check the email content and remove anything you do not want to share before sending it.

7. Contact

For support, use the in-app bug report where possible, the contact information provided in the Impressum, or the official App Store support link when available.

Please include enough technical detail to reproduce the issue. Support requests with clear steps can usually be handled faster than general descriptions such as “it does not work”.

8. Response time

Finalizer is an independent software project. Support is handled as quickly as possible, but response times may vary depending on workload, release schedule and issue complexity.
